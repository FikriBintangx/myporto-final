%----------PROJECTS----------
\section{Projects}
\begin{itemize}

\project{SmartOps Dual-Engine --- gRPC vs REST Benchmark}{Go, Node.js, gRPC, Protobuf, Docker}
\begin{bullets}
  \item Cut P99 latency by 71.6\% under 10,000+ req/sec concurrent load by moving the hot path from JSON/REST to gRPC with Protocol Buffers and persistent connection reuse.
  \item Built a reproducible benchmark harness that runs both engines against identical payloads and reports P50/P95/P99 and throughput per run.
  \item Containerized both services with Docker so results are comparable across machines.
\end{bullets}

\project{JurnalKu AI \& NotesBrain --- Semantic Search Backend}{Python, FastAPI, PostgreSQL + pgvector}
\begin{bullets}
  \item Kept API response times flat while indexing thousands of papers and documents by moving embedding and indexing into asynchronous worker queues off the HTTP request path.
  \item Implemented vector similarity search with pgvector in PostgreSQL, so semantic and relational queries share one database instead of a separate vector store.
  \item Added idempotent job handling so failed indexing jobs retry without creating duplicate records.
\end{bullets}

\project{Gatekeeper --- Auth \& Reverse-Proxy Gateway}{Go / Node.js, Redis, Nginx}
\begin{bullets}
  \item Blocked abusive traffic per client without penalizing normal users by implementing Redis sliding-window rate limiting in a reverse-proxy middleware.
  \item Closed timing side channels in credential checks by using constant-time comparison for tokens and secrets.
  \item Built a token rotation pipeline (short-lived access + rotating refresh tokens) with revocation of reused refresh tokens.
\end{bullets}

\project{Wahana Mobile API \& Admin Backoffice}{Node.js, Express, SQL, REST}
\begin{bullets}
  \item Reduced query overhead by 40\% by removing redundant JOINs and adding targeted indexes on the relational schema behind the admin backoffice.
  \item Standardized secure REST endpoints (input validation, consistent error format, auth middleware) shared by the mobile app and admin dashboard.
\end{bullets}

\end{itemize}
